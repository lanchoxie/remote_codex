# v2.4.8 Production Baseline

Release date: 2026-07-25

`v2.4.8` is the source snapshot currently serving the 8797 production Relay. It is based on `v2.4.7` and records the production fixes already applied to the stable installation.

## Highlights

- Stabilized session persistence, recovery, managed Session lifecycle, and Windows startup/restart handling.
- Improved API profile, model catalog, rebind, and per-Session runtime configuration handling.
- Normalized Connector deployment roots so repeated `.deployments/deploy-*` paths do not nest indefinitely.
- Added large-file chunked transfer support and transient network retry handling for Host Agents.
- Included the existing Skills, history/detail hydration, mobile transcript, and Windows Codex shim fixes from the production tree.

## Fixes

- Windows `.cmd`/`.bat` Codex shims are handled consistently by preflight and managed app-server startup.
- Session detail and history reads use the owning Host/runtime where available and avoid unnecessary full-history work.
- Connector status and deployment commands are rooted at the configured base directory.
- Large downloads use bounded chunks instead of one oversized base64 response.
- Managed Session start/stop/restart paths preserve explicit lifecycle state and retryable terminal outcomes.

## Scope Boundary

The newer 8897 development-only changes remain outside this tag until acceptance is complete. That includes the latest Thinking viewport race fix, the Markdown/LaTeX and matrix renderer, Host Codex update workflow, internal Approval/Guardian filtering, and the newest exactly-once input hardening.

## Verification

This tag is a source snapshot of the already-running 8797 installation. Runtime state, Session Store files, logs, credentials, Connector secrets, `tmp`, backups, and generated release archives are intentionally excluded.
