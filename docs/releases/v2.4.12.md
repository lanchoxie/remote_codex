# v2.4.12

Release date: 2026-11-08

This release publishes the source currently accepted on the isolated 8897 instance
and deployed on the 8797 Relay. It does not include Session data, credentials,
connector secrets, API keys, downloaded runtimes, or other machine-local state.

## Highlights

- Coordinated managed Session Start, Resume, and API rebind across browser tabs,
  including ordinary LAN/Tailscale HTTP origins without Web Locks. Launch intents
  retain stable request identities so an uncertain response does not silently
  create a second live run.
- Improved run/binding error reporting and model reasoning-effort metadata parsing.
  API compatibility is no longer rejected solely by comparing profile names;
  upstream failures remain visible without trimming conversation history.
- Preserved Thinking history and improved transcript reconciliation, notification
  read state, runtime indicators, and queue/interrupt display. Browser UI logic is
  split into smaller modules around the existing application entry point.
- Added a resizable in-page terminal for local and connected remote Hosts.
- Added an element-colored 3D structure viewer for XSF, PDB/PBD, XYZ, CIF, and
  VASP/POSCAR/CONTCAR files.
- Bounded Host Session discovery into metadata and preview batches. A failed
  initial discovery no longer prevents Agent heartbeat and command polling;
  oversized event requests return an explicit 413 error.
- Strengthened Relay persistence, historical transcript/attachment handling, and
  diagnostics around recoverable storage and import errors.
- Replaced outdated README screenshots with anonymous 8897 UI fixtures and
  documented the required `npm ci` installation step.

## Validation

- The isolated 8897 discovery acceptance exercised 167 synthetic Sessions across
  three batches, including previews and live-session preservation.
- Focused discovery, event persistence, Agent lease, and UI screenshot tests pass.
- On 2026-11-08 the 8797 Relay reported ready with writable persistence; the dm
  Host reconnected and reported 167 Sessions after discovery.

## Current Limits

- Generic `.dat` structure parsing is not implemented. The viewer only opens the
  supported structure formats listed above.
- Transfers of individual files larger than 2 GiB are not supported by the
  current file-transfer path.
- Updating the Relay source does not automatically upgrade every remote Host
  Agent. Apply the new Agent bundle through each connector when appropriate.
